# NNTN — Giới thiệu bản thân

Website trình chiếu giới thiệu bản thân bằng tiếng Việt, thiết kế responsive với 6 slide.

## Cách trình chiếu
- Mở `index.html` trên trình duyệt.
- Dùng phím **← / →** hoặc nút điều hướng để chuyển slide.
- Có thể dùng **Home** để về slide đầu, **End** để đến slide cuối.
- Trên điện thoại, vuốt sang trái/phải để chuyển slide.
- Nhấp vào phần **“Tên của bạn”** ở slide đầu để sửa tên trước khi trình chiếu.

## Chỉnh sửa nội dung
Mở `index.html` và tìm các phần `<section class="slide">`. Nội dung hiện tại là mẫu minh họa; hãy thay bằng tên, sở thích, điểm mạnh và mục tiêu thật của bạn.

## Bật GitHub Pages
1. Mở **Settings** của repository.
2. Chọn **Pages** ở thanh bên.
3. Trong **Build and deployment**, chọn **Deploy from a branch**.
4. Chọn branch **main**, thư mục **/(root)** rồi nhấn **Save**.
5. Sau khi GitHub triển khai xong, website sẽ có địa chỉ dạng:
   `https://mrbeastsupersigma.github.io/NNTN-indroduction/`

## Công nghệ
HTML, CSS và JavaScript thuần — không cần cài thư viện.
